# 01 · 需求规格书

## 1. 项目定位
基于皮卡鱼引擎（官方满级棋力）的桌面象棋 AI：自研界面 + 引擎魔改两条产品线。

## 2. 功能需求

### F1 棋盘对弈（GUI 线）
- F1.1 9×10 标准棋盘渲染，棋子拖拽/点击走子
- F1.2 中国象棋完整走子规则（马腿、塞象眼、士象活动范围、将帅不照面、过河兵）
- F1.3 人机对弈（玩家执红/执黑可选）、机机对弈
- F1.4 悔棋、认输、新局

### F2 引擎分析（GUI 线）
- F2.1 当前局面实时评估分（红方视角）
- F2.2 MultiPV 候选着法前 3 及各自分数
- F2.3 胜率曲线（随对局回合绘制）
- F2.4 引擎思考开关与思考时间/深度设置

### F3 复盘与开局库（GUI 线，后期）
- F3.1 对局记录（ICCS/中文记谱）保存与回放
- F3.2 开局库加载（obk 格式兼容为 Stretch 目标）

### F4 引擎魔改（引擎线）
- F4.1 搭建官方编译链，fork 后可独立编译出同棋力引擎
- F4.2 实验性参数改动（搜索剪枝、评估权重），以 bench + 自对弈回归验证

## 3. 非功能需求
- N1 棋力：不弱于官方 2026-09-06 版（GUI 侧直接挂官方引擎，天然满足）
- N2 界面响应：引擎分析刷新 <100ms；棋子动画 ≤300ms
- N3 平台：Windows 10+（GUI）；引擎跨平台按官方支持范围
- N4 GPL-3.0 合规：引擎衍生代码公开

## 4. 里程碑与验收标准
| 里程碑 | 内容 | 验收标准 |
|--------|------|----------|
| M1 引擎可用 | 下载+UCI 验证 | go depth 12 输出 bestmove |
| M2 GUI 骨架 | 棋盘渲染+摆子 | 能摆出任意合法局面并保存 FEN |
| M3 对弈闭环 | 规则+UCI 对接 | 人机完整对局一局无规则错误 |
| M4 分析功能 | 评估/MultiPV/胜率 | 每步实时刷新 <100ms |
| M5 引擎魔改 | fork+编译+首改 | bench 通过且棋力无明显回退 |
